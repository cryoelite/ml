# About this course

Gradient is a practical introduction to machine learning. It is for readers who want to know what ML can do, how it works, and how to decide whether to use it. No programming experience is required.

The course starts with a working model, then explains the ideas behind it. The chapters build from simple models to neural networks and language models. Most code runs in the browser. Optional articles and searchable appendices give you more detail when you want it.

## How to use the course

You can follow the chapters in order, or start from a topic that matches your goal. The home page offers paths for beginners, practical projects, deep learning, and language models. The [field map](/map/) shows the larger set of ideas and where this course stops.

For a project, begin with the task and the data. Make a simple baseline. Test it on examples it did not train on. Choose a measure that reflects the cost of mistakes. Then decide whether the model is useful enough to put in front of people.

The main path includes both the practical steps and the underlying ideas. It covers data, model choice, training, evaluation, and deployment. It also discusses bias and other ways a model can fail. No score alone proves that a system is safe or useful.

## Teaching choices

The course follows a few simple choices:

- **See a working example early.** Chapter 1 runs a classifier before introducing the vocabulary. Later lessons show the process behind that result.
- **Learn by trying.** Runnable examples let you change inputs, inspect outputs, and compare model behavior.
- **Spend time on likely sticking points.** Short explanations and exercises focus on ideas that often confuse new learners, such as overfitting, data leakage, and gradients.
- **Use more than one kind of example.** The course moves from tables to images and text so you can see which ideas carry over and which depend on the data.
- **Keep a route open after the last chapter.** The final lesson explains how to keep learning from projects, documentation, and research papers.

This approach draws on Jeremy Howard and Sylvain Gugger's application-first fastai course and book, and David Perkins's *Making Learning Whole*. Perkins emphasizes learning the complete task, practicing difficult parts, and learning how to continue independently. The book's ideas helped shape the order of the lessons and the exercises.

## Sources and further study

The supplied books informed the course. They are references, not text to copy.

- **Jeremy Howard and Sylvain Gugger, *Deep Learning for Coders with fastai and PyTorch* (O’Reilly, 2020).** Used as a reference for practical deep learning, project choice, and the relationship between applications and theory. The [fastai course](https://course.fast.ai/) and [book notebooks](https://github.com/fastai/fastbook) are available online.
- **David Perkins, *Making Learning Whole: How Seven Principles of Teaching Can Transform Education* (Jossey-Bass, 2009).** Informed the use of complete tasks, focused practice, varied examples, and a path for learning beyond this course.
- **Seth Weidman, *Deep Learning from Scratch* (O’Reilly, 2019).** A reference for neural-network mathematics and from-scratch implementations.

For current, maintained learning resources, see [Google's Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course), the [scikit-learn guide](https://scikit-learn.org/stable/getting_started.html), and [PyTorch's beginner tutorials](https://docs.pytorch.org/tutorials/beginner/basics/intro.html).

Research claims are linked near the lesson where they appear. Software instructions can change, so check the official documentation before installing a library or following a platform-specific setup step.

## How the site works

The site is built with Astro and MDX. Lesson text is regular Markdown with a few components for interactive code, exercises, notes, and math. Python cells run through Pyodide in the browser, or through a Jupyter kernel on your own computer when a lesson needs PyTorch.

The site is designed to work as static pages. JavaScript adds the interactive features, but the explanations and links remain available without them. The project guidance and developer commands are in [AGENTS.md](https://github.com/cryoelite/ml/blob/main/AGENTS.md) and the [README](https://github.com/cryoelite/ml/blob/main/README.md).
