# Setup

You can read the course and run most examples without installing anything. Python runs in your browser when you press **Run**. Come back to this page if you want to run the site on your computer or reach the PyTorch lessons.

## What runs where?

| | In your browser | On your computer |
|---|---|---|
| What runs | Python compiled to WebAssembly (Pyodide) | A local Jupyter kernel |
| Install needed | No | Yes, for the PyTorch lessons |
| Used for | Most examples in the course | Chapter 10 and examples marked `local` |

The site does not host a shared Python kernel. The local kernel runs on your computer and the browser connects to it.

## Run the site on your computer

The simplest option is [Docker Desktop](https://docs.docker.com/get-started/get-docker/):

```bash
docker compose up --build
```

Open `http://localhost:4321`. Stop the site with `Ctrl+C`.

For development, install [Bun](https://bun.sh), then run:

```bash
bun run setup
bun run dev
```

The setup command installs the site packages and the browser Python runtime. It also creates a light Python environment for the course tools. To include PyTorch now, use `bun run setup --deep`.

## Run the PyTorch lessons

First, download the project code using the instructions on the [GitHub repository](https://github.com/cryoelite/ml). Install [uv](https://docs.astral.sh/uv/), then start the kernel from the project folder.

**macOS or Linux**

```bash
bash kernel/run.sh
```

**Windows PowerShell**

```powershell
powershell -ExecutionPolicy Bypass -File kernel\run.ps1
```

The first run installs PyTorch and may take a few minutes. Leave the terminal open. In the site header, open the runtime menu, choose **On this machine**, then select **Test connection**.

<Aside type="nice">
On Apple Silicon, run the script on macOS if you want to use the Metal GPU. Docker on macOS runs the kernel without access to that GPU. CPU mode still works for the course examples.
</Aside>

## If the site is hosted elsewhere

The kernel accepts browser connections from localhost by default. If the course is open on a hosted website, tell the kernel that site's origin before starting it.

**macOS or Linux**

```bash
GRADIENT_SITE_ORIGIN=https://example.com bash kernel/run.sh
```

**Windows PowerShell**

```powershell
$env:GRADIENT_SITE_ORIGIN = "https://example.com"
powershell -ExecutionPolicy Bypass -File kernel\run.ps1
```

Replace `https://example.com` with the address in your browser. The kernel only listens on your own computer and requires a token. Keep the terminal running while you use the PyTorch cells.

## Common problems

- **The connection test cannot reach the kernel:** make sure the kernel terminal is still open. The default address is `http://127.0.0.1:8899` and the default token is `gradient`.
- **The site is hosted over HTTPS:** browsers restrict connections to local services. Try a recent version of Chrome or Firefox, or run the site locally.
- **Port 8899 is already in use:** start the kernel with a different `GRADIENT_KERNEL_PORT` value, then enter the same port in the runtime menu.
- **A dataset or model download fails on macOS:** some Python installers need their certificate bundle set up. See [Python's certificate instructions](https://docs.python.org/3/using/mac.html#installing-certificates).

If you only want to learn from the browser lessons, you can ignore the rest of this page.
