A linear model predicts a weighted sum of its input features plus a bias:

$$\hat{y} = w \cdot x + b$$

Each weight describes how that feature contributes to the prediction. The bias is the prediction when all features are zero.

A neuron applies an activation function to a linear transformation. Neural-network layers combine many such transformations.
