The hat is the convention worth internalising: $y$ is what actually happened,
$\hat{y}$ is what the model guessed. Loss functions are always some measure of
the distance between them.

Each weight is the answer to "how much does this feature move the prediction,
per unit". The bias is what the model predicts when every feature is zero —
without it the model is forced through the origin, which is rarely what you
want.

A single neuron is exactly this, followed by a nonlinearity. A layer is a
stack of them, which is why a layer is a matrix multiply.
