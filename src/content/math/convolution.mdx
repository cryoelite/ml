A convolution applies the same small set of weights, called a kernel, at each position in an input. For an image, a 3-by-3 kernel combines a patch of nine pixels into one output value, then moves to the next patch.

Reusing the weights is called weight sharing. It lets the model detect a pattern, such as an edge, in different parts of an image with fewer parameters.

Many deep-learning libraries implement cross-correlation under the name convolution; the learned kernel is not flipped as it is in the mathematical definition. Convolutions work well when local patterns and their locations matter.
