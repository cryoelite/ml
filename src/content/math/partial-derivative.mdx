A partial derivative measures how a function changes when one input changes and all other inputs stay fixed.

A model’s loss depends on many parameters. The partial derivative for one parameter describes how a small change to that parameter affects the loss.

Collect the partial derivatives for all parameters and you have the [gradient](/appendix/math/#gradient).
