---
title: 'Scaled dot-product attention'
summary: "Compare each query with keys, then combine values using the resulting weights."
formula: '\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V'
docs: 'https://arxiv.org/abs/1706.03762'
docsLabel: 'Attention Is All You Need ↗'
symbols:
  - sym: 'Q'
    means: 'queries: what each position is looking for'
  - sym: 'K'
    means: 'keys: what each position offers'
  - sym: 'V'
    means: 'values: what each position actually contributes'
  - sym: 'K^{\top}'
    means: 'K transposed, so QK-transpose is every query against every key'
  - sym: '\sqrt{d_k}'
    means: 'a scale factor keeping the dot products from growing with dimension'
---
Read the formula from right to left. First, each query is compared with every key using a dot product. Divide the scores by $\sqrt{d_k}$, then apply softmax so each row becomes weights that sum to one. The weighted sum of the values gives each position its output.

In words: each position looks for relevant information and combines the values it finds.

The score matrix has one entry for every pair of positions, so its size grows as sequence length squared. This can make standard attention expensive for long inputs.
