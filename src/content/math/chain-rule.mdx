The chain rule finds the derivative of a function built from nested functions. Multiply the local derivatives, evaluating each derivative at the output of the function before it.

For example, if a loss changes by 3 for each unit change in an intermediate value, and that value changes by 2 for each unit change in the input, then the loss changes by 6 per input unit.

Backpropagation applies the chain rule through a neural network. It also explains why gradients can shrink or grow as they pass through many layers.
