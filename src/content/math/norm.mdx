A norm gives the length of a vector. The L2 norm is Euclidean length; the L1 norm sums the absolute values of its components.

Norms also appear in regularisation. L2 penalties tend to shrink weights, while L1 penalties can set some weights to zero.

Gradient clipping uses the L2 norm to limit the size of an update. If the gradient exceeds a chosen threshold, it is scaled down.
