The Jacobian is a matrix of partial derivatives for a function with multiple outputs. Each row corresponds to an output; each column corresponds to an input.

For a composition of functions, the chain rule becomes matrix multiplication:

$$J_{f \circ g} = J_f J_g$$

Backpropagation applies these derivatives in reverse through a network. Deep-learning frameworks usually compute the products needed for gradients without building the full Jacobian matrix, which could be too large to store.
