Each output entry in a matrix product is the dot product of one row from the first matrix and one column from the second.

The inner dimensions must match and disappear from the output shape. For example, $(32,784)(784,128)$ produces a matrix with shape $(32,128)$: 32 examples and 128 outputs per example.

A neural-network layer uses matrix multiplication to apply weights to a batch of examples.
