Gradient descent updates parameters by moving opposite the gradient of the loss:

$$\theta_{t+1} = \theta_t - \eta\nabla_\theta L(\theta_t)$$

The gradient points toward the steepest local increase in loss. The learning rate $\eta$ sets the step size. A step that is too large can make training unstable; one that is too small can make it slow.

Momentum uses past gradients to smooth the update. Adam adapts step sizes using running estimates of gradient statistics. These methods change the update rule, but they still use gradients to reduce the loss.
