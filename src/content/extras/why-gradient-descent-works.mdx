A bowl-shaped loss is a useful picture for a simple linear model. Neural-network loss surfaces are more complicated. This article explains why gradient methods can still work well in practice, and where our explanations remain incomplete.

## Convex and non-convex losses

A convex function has no separate, worse local minimum: any local minimum is also a global minimum. Squared-error linear regression and logistic regression with standard formulations have convex objectives.

Neural networks are generally non-convex. Their loss can have many critical points, where the gradient is zero.

```python run setup title="convex and not"
import numpy as np, matplotlib.pyplot as plt

x = np.linspace(-3, 3, 400)
convex     = x ** 2
nonconvex  = x ** 4 - 3 * x ** 2 + 0.6 * x + 3

fig, ax = plt.subplots(1, 2, figsize=(8.4, 2.9))
ax[0].plot(x, convex); ax[0].set_title("convex: one minimum, always findable")
ax[1].plot(x, nonconvex); ax[1].set_title("non-convex: where do you end up?")
for a in ax: a.set_xticks([]); a.set_yticks([])
plt.tight_layout()
```

Different starting points can lead to different outcomes on a non-convex function.

```python run title="where you land depends on where you start"
def descend(f, df, x0, lr=0.01, steps=600):
    x = x0
    for _ in range(steps):
        x -= lr * df(x)
    return x

f  = lambda x: x ** 4 - 3 * x ** 2 + 0.6 * x + 3
df = lambda x: 4 * x ** 3 - 6 * x + 0.6

for start in [-2.5, -0.5, 0.4, 2.5]:
    end = descend(f, df, start)
    print(f"start {start:+.1f}  ->  end {end:+.3f}   loss {f(end):.3f}")
```

This example shows that possibility in one dimension. It does not show what happens in every neural network, but it explains why convex optimisation results do not directly settle deep-network training.

## Saddles in high dimensions

A critical point is a local minimum only if the loss curves upward in every direction. It is a saddle if some directions curve up and others curve down.

```python run title="the probability of a minimum, by dimension"
rng = np.random.default_rng(0)

def critical_point_types(dim, trials=400):
    """Random symmetric Hessians: minima need every eigenvalue positive."""
    minima = saddles = maxima = 0
    for _ in range(trials):
        A = rng.normal(size=(dim, dim))
        H = (A + A.T) / 2                       # a random symmetric matrix
        ev = np.linalg.eigvalsh(H)
        if (ev > 0).all():   minima += 1
        elif (ev < 0).all(): maxima += 1
        else:                saddles += 1
    return minima / trials, saddles / trials, maxima / trials

print(f"{'dimensions':>11s} {'minima':>9s} {'saddles':>9s} {'maxima':>8s}")
for dim in [1, 2, 5, 10, 20]:
    mn, sd, mx = critical_point_types(dim)
    print(f"{dim:11d} {mn:9.3f} {sd:9.3f} {mx:8.3f}")
```

For the random matrices in this demonstration, saddle-shaped critical points become more common as dimension grows. A neural-network loss surface is not a random symmetric matrix, so this is an illustration of high-dimensional geometry, not proof that neural-network minima are rare.

Small amounts of stochastic variation can sometimes help an optimiser move away from a saddle, but the effect depends on the landscape and optimiser.

```python run title="escaping a saddle, with and without noise"
# f(x,y) = x^2 - y^2 : the textbook saddle, sitting exactly at the origin
def run(noise, steps=60, lr=0.1, seed=0):
    r = np.random.default_rng(seed)
    p = np.array([0.0, 1e-7])          # essentially at the saddle
    path = [p.copy()]
    for _ in range(steps):
        g = np.array([2 * p[0], -2 * p[1]])
        p -= lr * (g + r.normal(0, noise, 2))
        path.append(p.copy())
    return np.array(path)

clean = run(0.0)
noisy = run(0.02)
print(f"clean gradient : after 60 steps, distance from saddle {np.abs(clean[-1]).max():.2e}")
print(f"noisy gradient : after 60 steps, distance from saddle {np.abs(noisy[-1]).max():.2e}")
print("\nthe clean run is still crawling off the saddle. the noisy one left.")
```

## Different solutions can perform similarly

Neural networks can represent the same function with different parameter settings. For example, permuting hidden units and their corresponding weights may leave predictions unchanged. Overparameterised models can also have many low-training-loss solutions.

That does not mean all minima are equally good. Some solutions generalise better than others, and training loss alone cannot tell us which one will perform best on new data.

This example trains a small model from several starting points and compares its results.

```python run title="many random starts, similar answers"
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split

X, y = make_moons(n_samples=600, noise=0.2, random_state=0)
X = (X - X.mean(0)) / X.std(0)
Xtr, Xva, ytr, yva = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)

def train(seed, hidden=32, steps=1500, lr=0.5):
    r = np.random.default_rng(seed)
    W1 = r.normal(0, np.sqrt(2 / 2), (2, hidden)); b1 = np.zeros(hidden)
    W2 = r.normal(0, np.sqrt(2 / hidden), (hidden, 1)); b2 = np.zeros(1)
    for _ in range(steps):
        a1 = np.maximum(0, Xtr @ W1 + b1)
        p = 1 / (1 + np.exp(-(a1 @ W2 + b2)))
        d2 = (p - ytr.reshape(-1, 1)) / len(ytr)
        d1 = (d2 @ W2.T) * (a1 > 0)
        W2 -= lr * a1.T @ d2; b2 -= lr * d2.sum(0)
        W1 -= lr * Xtr.T @ d1; b1 -= lr * d1.sum(0)
    a1 = np.maximum(0, Xva @ W1 + b1)
    pv = 1 / (1 + np.exp(-(a1 @ W2 + b2)))
    pt = 1 / (1 + np.exp(-(np.maximum(0, Xtr @ W1 + b1) @ W2 + b2)))
    ptc = np.clip(pt.ravel(), 1e-9, 1 - 1e-9)
    loss = -(ytr * np.log(ptc) + (1 - ytr) * np.log(1 - ptc)).mean()
    return loss, ((pv.ravel() > 0.5).astype(int) == yva).mean(), W1

results = [train(s) for s in range(8)]
print(f"{'seed':>4s} {'final train loss':>18s} {'valid accuracy':>16s}")
for s, (loss, acc, _) in enumerate(results):
    print(f"{s:4d} {loss:18.4f} {acc:16.3f}")
losses = [r[0] for r in results]
print(f"\nloss spread: {min(losses):.4f} to {max(losses):.4f}"
      f"  (range is {100 * (max(losses) - min(losses)) / min(losses):.1f}% of the minimum)")
```

## Robustness to small changes

A flat region of a loss surface changes less under a small parameter shift than a sharp region.

```python run title="sharp and flat, and what happens when the world shifts"
xs = np.linspace(-2, 2, 400)
sharp = 30 * xs ** 2
flat  = 1.2 * xs ** 2

fig, ax = plt.subplots(figsize=(5.4, 3))
ax.plot(xs, sharp, label="sharp minimum")
ax.plot(xs, flat, label="flat minimum")
ax.axvline(0.35, ls=":", c="grey")
ax.text(0.4, 22, "test data shifts\nthe minimum slightly", fontsize=7.5, color="grey")
ax.set_ylim(0, 30); ax.set_xlabel("parameter"); ax.set_ylabel("loss")
ax.legend(fontsize=8); plt.tight_layout()

shift = 0.35
print(f"if the true minimum moves by {shift}:")
print(f"  sharp: loss goes 0 -> {30 * shift ** 2:.2f}")
print(f"  flat : loss goes 0 -> {1.2 * shift ** 2:.2f}")
```

Flatness can be useful intuition, but its measurement depends on parameter scale and representation. It is not a complete explanation of generalisation. Evaluate performance on data the model did not train on.

## Why stochastic gradient methods work

Mini-batch training uses an estimate of the full-data gradient. That estimate is noisy, but it is much cheaper to calculate. Noise may help with some optimisation problems; it can also make training less stable. Large batches do not always hurt generalisation, and small batches do not guarantee a better solution.

Overparameterisation can make optimisation easier in many practical settings, but there is no single explanation that covers all networks, datasets, and training procedures.

## What remains difficult

Training can still fail because of poorly scaled data, unsuitable learning rates, bad initialisation, unstable losses, or bugs. Some tasks, including sparse-reward reinforcement learning and adversarial training, are especially difficult.

There is no general theorem showing that gradient descent always finds a useful solution for every deep network. Current understanding combines experiments, results under simplifying assumptions, and practices that work well in tested settings.

When an intuition disagrees with held-out results, inspect the data and evaluation and trust the measurements. Use theories of optimisation to form hypotheses, then test them.
