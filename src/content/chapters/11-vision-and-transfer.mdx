Images contain spatial structure: nearby pixels often belong to the same edge, texture, or object. A dense layer treats each pixel as a separate input. Convolutional layers use local filters and share the same weights across image locations.

## Keep image structure

A dense layer connected to every pixel can require many parameters and does not automatically recognize the same feature in another location.

```python run setup title="the arithmetic that kills it"
import numpy as np, matplotlib.pyplot as plt
from sklearn.datasets import load_digits

digits = load_digits()
images = digits.images          # (1797, 8, 8)
print("tiny images:", images.shape)

for h, w, hidden in [(8, 8, 100), (28, 28, 100), (224, 224, 1000)]:
    n_in = h * w * (3 if h > 100 else 1)
    print(f"{h}x{w} -> dense({hidden})   {n_in * hidden:,} weights in the first layer alone")
```

If a model learns an edge at one pixel position, a fully connected layer does not automatically reuse that feature elsewhere. Convolution addresses this by applying the same filter across the image.

## Apply a convolution

A convolution slides a small grid of weights, called a kernel or filter, across the image. It computes a weighted sum at each position.

```python run title="a kernel is a tiny template"
def convolve2d(image, kernel):
    kh, kw = kernel.shape
    h, w = image.shape
    out = np.zeros((h - kh + 1, w - kw + 1))
    for i in range(out.shape[0]):
        for j in range(out.shape[1]):
            out[i, j] = (image[i:i + kh, j:j + kw] * kernel).sum()
    return out

vertical   = np.array([[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]], float)   # Sobel
horizontal = vertical.T
blur       = np.ones((3, 3)) / 9

img = images[0]
fig, ax = plt.subplots(1, 4, figsize=(9, 2.5))
for a, (name, k) in zip(ax, [("original", None), ("vertical edges", vertical),
                             ("horizontal edges", horizontal), ("blur", blur)]):
    a.imshow(img if k is None else convolve2d(img, k), cmap="gray")
    a.set_title(name, fontsize=9); a.axis("off")
plt.tight_layout()
```

A small kernel can respond to patterns such as edges. Training can learn the kernel weights from data.

```python run title="weight sharing, counted"
h = w = 224
dense_first_layer = (h * w * 3) * 64
conv_first_layer  = 3 * 3 * 3 * 64 + 64          # 3x3 kernel, 3 in, 64 out
print(f"dense(64) on 224x224x3 : {dense_first_layer:>12,} weights")
print(f"conv 3x3, 64 filters   : {conv_first_layer:>12,} weights")
print(f"ratio                  : {dense_first_layer / conv_first_layer:>12,.0f}x fewer")
```

Sharing the same weights at every location greatly reduces the number of parameters. It also encodes an assumption: a useful local pattern can matter wherever it appears. Convolution is therefore a good fit for images, where local structure is meaningful.

## Channels, stride, padding, and pooling

A convolutional layer has several settings:

- **Channels** describe the input and output feature maps. A colour image has three input channels; a layer can produce many learned output channels.
- **Stride** controls how far the filter moves. A stride of two reduces the spatial size.
- **Padding** adds values around the border. Padding can preserve the width and height for a chosen kernel.
- **Pooling** reduces spatial dimensions by summarizing small regions, often with a maximum or average.

```python run title="the shapes, worked out"
def conv_out(size, kernel, stride=1, pad=0):
    return (size + 2 * pad - kernel) // stride + 1

size = 224
print(f"{'layer':28s} {'out':>6s}")
for label, k, s, p in [("conv 3x3 pad 1", 3, 1, 1), ("conv 3x3 pad 1", 3, 1, 1),
                       ("maxpool 2x2 stride 2", 2, 2, 0), ("conv 3x3 pad 1", 3, 1, 1),
                       ("maxpool 2x2 stride 2", 2, 2, 0)]:
    size = conv_out(size, k, s, p)
    print(f"{label:28s} {size:>6d}")
```

As a network gets deeper, it often uses fewer spatial positions and more channels. Early layers retain precise location information; later layers combine features over larger regions.

## Build a convolutional network

The next examples define and train a convolutional model on small digit images:

```python run local setup title="a convnet on 8x8 digits"
import torch, torch.nn as nn
from sklearn.model_selection import train_test_split
from sklearn.datasets import load_digits

d = load_digits()
X = torch.tensor(d.images, dtype=torch.float32).unsqueeze(1) / 16.0   # (n, 1, 8, 8)
y = torch.tensor(d.target, dtype=torch.long)
Xtr, Xva, ytr, yva = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)

class ConvNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 16, 3, padding=1), nn.BatchNorm2d(16), nn.ReLU(),
            nn.Conv2d(16, 32, 3, padding=1), nn.BatchNorm2d(32), nn.ReLU(),
            nn.MaxPool2d(2),                       # 8x8 -> 4x4
        )
        self.head = nn.Sequential(nn.Flatten(), nn.Linear(32 * 4 * 4, 10))
    def forward(self, x):
        return self.head(self.features(x))

torch.manual_seed(0)
net = ConvNet()
print("parameters:", sum(p.numel() for p in net.parameters()))
```

```python run local title="train it"
from torch.utils.data import TensorDataset, DataLoader

dl = DataLoader(TensorDataset(Xtr, ytr), batch_size=64, shuffle=True)
opt = torch.optim.AdamW(net.parameters(), lr=3e-3)
loss_fn = nn.CrossEntropyLoss()          # softmax is inside the loss

for epoch in range(8):
    net.train()
    for xb, yb in dl:
        opt.zero_grad(); loss_fn(net(xb), yb).backward(); opt.step()
    net.eval()
    with torch.no_grad():
        acc = (net(Xva).argmax(1) == yva).float().mean()
    print(f"epoch {epoch+1}  valid accuracy {acc:.3f}")
```

The training loop is the same as before. The architecture changes how the model processes the data.

The model returns one score per digit. Cross-entropy takes those logits and the integer class labels, then computes the classification loss. Batch normalization is another common layer; it normalizes activations using statistics from the training data and can help stabilize optimization.

## Transfer learning

A pretrained image model has already learned useful visual features. Transfer learning adapts it to a new task: replace its final classification layer, then train that layer on the new labels.

```python run local title="borrow a network that has already seen 14 million photos"
import torchvision
from torchvision.models import resnet18, ResNet18_Weights

weights = ResNet18_Weights.DEFAULT
backbone = resnet18(weights=weights)     # downloads ~45 MB once, then cached

total = sum(p.numel() for p in backbone.parameters())
print(f"resnet18: {total:,} parameters, pretrained on ImageNet")
print("final layer:", backbone.fc)

# Replace the 1000-class head with your own.
backbone.fc = nn.Linear(backbone.fc.in_features, 5)     # 5 classes of yours
print("replaced with:", backbone.fc)

# Freeze everything except the new head, for the first phase of training.
for name, p in backbone.named_parameters():
    p.requires_grad = name.startswith("fc")
trainable = sum(p.numel() for p in backbone.parameters() if p.requires_grad)
print(f"trainable now: {trainable:,} of {total:,}  ({trainable / total:.2%})")
```

This can reduce the amount of labelled data needed compared with training an entire image model from scratch. It does not guarantee good results; the new data and task still need to be evaluated.

A common procedure is:

1. Freeze the pretrained layers and train the new classification head.
2. Unfreeze some or all of the model and continue training with a lower learning rate.
3. Optionally use different learning rates for different layers.

The lower rate helps preserve useful features while adapting them to the new task.

```python run local title="phase two"
for p in backbone.parameters():
    p.requires_grad = True

opt = torch.optim.AdamW([
    {"params": backbone.layer1.parameters(), "lr": 1e-5},   # generic: barely touch
    {"params": backbone.layer4.parameters(), "lr": 1e-4},   # task-ish
    {"params": backbone.fc.parameters(),     "lr": 1e-3},   # brand new
])
print("three parameter groups, three learning rates:")
for g in opt.param_groups:
    print(f"  lr={g['lr']:<8} {sum(p.numel() for p in g['params']):>10,} params")
```

## Data augmentation

Data augmentation creates additional training examples by applying transformations that keep the label correct.

```python run title="what augmentation does, conceptually"
img = images[7]
fig, ax = plt.subplots(1, 5, figsize=(10, 2.2))
variants = [
    ("original",   img),
    ("flip",       img[:, ::-1]),
    ("shift",      np.roll(img, 1, axis=0)),
    ("brighter",   np.clip(img * 1.5, 0, 16)),
    ("noise",      np.clip(img + np.random.default_rng(0).normal(0, 1.2, img.shape), 0, 16)),
]
for a, (name, v) in zip(ax, variants):
    a.imshow(v, cmap="gray"); a.set_title(name, fontsize=9); a.axis("off")
plt.tight_layout()
```

A flip, crop, or brightness change may be appropriate for one task and harmful for another. A horizontal flip may preserve a cat label, but it can change the meaning of text, digits, or road signs. Choose transformations based on the data and task.

Apply augmentation to training examples. Evaluate on a separate set that represents the examples the model will see in use.

## Current approaches to computer vision

Convolutional networks are still widely used. Vision Transformers divide an image into patches and process them with transformer layers. They can work well, especially with sufficient data and compute, while convolutional models build in a useful assumption about local image structure. Hybrid architectures combine ideas from both.

The best choice depends on the dataset, compute budget, and intended use. Pretrained models are a useful starting point for either architecture family.

Applying an edge detector to an edge map responds to changes in edge strength, such as corners or line ends. This is a simple example of how later layers can combine earlier features.

In a convolutional network, early filters may detect local patterns. Later layers combine those patterns into more complex features. The learned hierarchy depends on the data and training process; it is not prescribed by hand.
