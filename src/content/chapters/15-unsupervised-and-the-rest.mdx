Many tasks have no target label for each example. Clustering can group similar records; dimensionality reduction can summarize data with fewer numbers. This chapter introduces those methods and points to other areas of machine learning.

## Clustering

K-means groups examples by alternating two steps: assign each example to its nearest centre, then move each centre to the mean of its assigned examples.

```python run setup title="k-means, implemented"
import numpy as np, matplotlib.pyplot as plt
from sklearn.datasets import make_blobs

X, true_labels = make_blobs(n_samples=400, centers=4, cluster_std=1.1, random_state=7)

def kmeans(X, k, iters=25, seed=0):
    rng = np.random.default_rng(seed)
    centres = X[rng.choice(len(X), k, replace=False)]      # start on real points
    for _ in range(iters):
        d = ((X[:, None, :] - centres[None, :, :]) ** 2).sum(-1)   # (n, k) distances
        assign = d.argmin(1)                                        # nearest centre
        for j in range(k):                                          # move each centre
            if (assign == j).any():
                centres[j] = X[assign == j].mean(0)
    return assign, centres

assign, centres = kmeans(X, 4)
print("cluster sizes:", np.bincount(assign))
```

The result is a set of clusters:

```python run title="what it found"
fig, ax = plt.subplots(1, 2, figsize=(8.4, 3.2))
ax[0].scatter(X[:, 0], X[:, 1], c=true_labels, s=10, cmap="tab10")
ax[0].set_title("the truth (which you would not have)")
ax[1].scatter(X[:, 0], X[:, 1], c=assign, s=10, cmap="tab10")
ax[1].scatter(centres[:, 0], centres[:, 1], c="k", marker="X", s=120)
ax[1].set_title("what k-means found")
for a in ax: a.set_xticks([]); a.set_yticks([])
plt.tight_layout()
```

K-means has important limits:

- You must choose the number of clusters. The elbow method and silhouette score can help explore choices, but neither proves the correct number.
- It works best for roughly compact clusters under the chosen distance measure. Other shapes may need a different method, such as density-based clustering.
- Without labels, no score can tell you whether the groups are meaningful for your use. Ask whether the groups help answer the original question.

The next example shows why minimizing the within-cluster distance alone cannot choose the number of clusters:

```python run title="the elbow, and its limits"
inertias = []
for k in range(1, 9):
    a, c = kmeans(X, k)
    inertias.append(((X - c[a]) ** 2).sum())
plt.figure(figsize=(4.8, 2.8))
plt.plot(range(1, 9), inertias, "o-"); plt.axvline(4, ls=":", c="crimson")
plt.xlabel("k"); plt.ylabel("within-cluster sum of squares"); plt.tight_layout()
print("inertia always falls with k — at k = n it is exactly zero, and useless")
```

That distance, often called inertia, falls as you add clusters. At one cluster per example it can reach zero, which does not make it a useful solution. Use the score alongside plots and domain knowledge.

## Reduce dimensionality

Principal component analysis (PCA) finds directions of greatest variance in the data. It rotates the data into new coordinates ordered by how much variance each direction explains.

```python run title="PCA, which is just rotation"
from sklearn.datasets import load_digits
d = load_digits()
Xd = d.data - d.data.mean(0)                  # centre first; PCA requires it

# PCA via SVD — the numerically sane way
U, S, Vt = np.linalg.svd(Xd, full_matrices=False)
explained = S ** 2 / (S ** 2).sum()

print(f"64 original dimensions")
for k in [2, 8, 16, 32]:
    print(f"  first {k:2d} components explain {explained[:k].sum():.1%} of the variance")
```

The rotation itself keeps all the information. Compression happens when you keep only the first few components and discard the rest.

```python run title="64 dimensions, drawn in 2"
proj = Xd @ Vt[:2].T
plt.figure(figsize=(5.4, 4))
sc = plt.scatter(proj[:, 0], proj[:, 1], c=d.target, s=7, cmap="tab10")
plt.colorbar(sc, label="true digit"); plt.xticks([]); plt.yticks([])
plt.title("digits projected onto their two principal components")
plt.tight_layout()
```

PCA can reveal structure in a lower-dimensional view, but the projection can hide differences. Standardize features first when their scales should contribute comparably.

Nonlinear methods such as UMAP and t-SNE can help visualize local neighbourhoods. Their layouts depend on settings and random initialization; distances between separated groups may not reflect how different those groups are. Treat such plots as exploratory views, not proof of clusters.

## Autoencoders

An autoencoder learns to reconstruct its input through a smaller representation. The narrow layer is called a bottleneck.

```python run local setup title="an autoencoder"
import torch, torch.nn as nn

Xt = torch.tensor(d.data / 16.0, dtype=torch.float32)

class AutoEncoder(nn.Module):
    def __init__(self, n_in=64, latent=8):
        super().__init__()
        self.encode = nn.Sequential(nn.Linear(n_in, 32), nn.ReLU(), nn.Linear(32, latent))
        self.decode = nn.Sequential(nn.Linear(latent, 32), nn.ReLU(), nn.Linear(32, n_in))
    def forward(self, x):
        return self.decode(self.encode(x))

torch.manual_seed(0)
ae = AutoEncoder()
opt = torch.optim.AdamW(ae.parameters(), lr=3e-3)
for epoch in range(400):
    opt.zero_grad()
    loss = nn.functional.mse_loss(ae(Xt), Xt)     # the target IS the input
    loss.backward(); opt.step()
print(f"reconstruction MSE: {loss.item():.4f}   (8 numbers stand in for 64)")
```

The next example shows what information survived that bottleneck:

```python run local title="what survived the bottleneck"
with torch.no_grad():
    recon = ae(Xt[:8]).reshape(-1, 8, 8).numpy()
fig, ax = plt.subplots(2, 8, figsize=(9, 2.4))
for i in range(8):
    ax[0, i].imshow(d.images[i], cmap="gray"); ax[0, i].axis("off")
    ax[1, i].imshow(recon[i], cmap="gray"); ax[1, i].axis("off")
ax[0, 0].set_title("original", fontsize=8, loc="left")
ax[1, 0].set_title("through 8 numbers", fontsize=8, loc="left")
plt.tight_layout()
```

The model learns from the input itself, so no separate labels are needed. An autoencoder can also support anomaly detection: train on examples considered normal, then investigate examples with large reconstruction errors.

Reconstruction error is not a reliable anomaly score in every task. An unusual example may still reconstruct well, and a normal example may reconstruct poorly. Validate the approach with examples and review how false alarms will be handled.

## Other areas of machine learning

This course covers only part of the field. The [extras](/extras/) introduce more topics.

### Generative models

Generative models create new examples. Generative adversarial networks (GANs) train a generator against a discriminator. Diffusion models learn to remove noise from examples and can generate new samples by reversing a noise process.

### Reinforcement learning

In reinforcement learning, an agent takes actions and receives rewards. Feedback may be delayed, and actions affect the data the agent sees next. The area includes methods such as Q-learning and policy gradients. It is used in robotics, games, and some model post-training.

### Graph neural networks

Graph neural networks pass information between connected nodes. They are useful when the structure itself is a graph, such as a molecule, road network, or social network.

### Probabilistic methods

Bayesian methods and probabilistic models represent uncertainty explicitly. They can be useful when data is limited, when decisions depend on uncertainty, or when the model needs to combine prior knowledge with observations.

### Time series

Time-series methods forecast measurements ordered in time. Classical models such as exponential smoothing and ARIMA can be useful, especially for smaller datasets. Validate on later periods, not a random split.

These areas use many of the same ideas as earlier chapters: data, a model, a fitting method, and an evaluation plan. Use the field map to place a new method and learn more when it fits a task you care about.

The first example shows how much cluster assignments can change with initialization:

```python run
print("k-means is sensitive to initialisation:")
for seed in range(5):
    a, c = kmeans(X, 4, seed=seed)
    print(f"  seed {seed}: inertia {((X - c[a]) ** 2).sum():9.1f}   sizes {np.bincount(a, minlength=4)}")
```

K-means can converge to different local solutions. Libraries often run it from several initializations and keep the result with the lowest inertia. This improves reliability but does not guarantee a global optimum.

The next example compares PCA reconstructions:

```python run
fig, ax = plt.subplots(5, 6, figsize=(7.5, 6.2))
for row, k in enumerate([2, 4, 8, 16, 64]):
    approx = (Xd @ Vt[:k].T) @ Vt[:k] + d.data.mean(0)
```

Keeping more components preserves more detail. Choose a compression level based on the information needed for the task.

Finally, compare reconstruction error for one digit class against the others:

```python run
normal = d.data[d.target != 3]
odd    = d.data[d.target == 3]
mu = normal.mean(0)
_, _, V = np.linalg.svd(normal - mu, full_matrices=False)
k = 8

def recon_error(A):
    C = A - mu
    return (((C @ V[:k].T) @ V[:k] - C) ** 2).mean(1)

en, eo = recon_error(normal), recon_error(odd)
print(f"reconstruction error, digits 0-9 except 3 : {en.mean():.2f}")
print(f"reconstruction error, digit 3 (unseen)    : {eo.mean():.2f}")
thresh = np.percentile(en, 95)
far, det = (en > thresh).mean(), (eo > thresh).mean()
print(f"\nflagging error > {thresh:.1f} (95th pct of normal):")
print(f"  false alarm rate on normal : {far:.1%}")
print(f"  detection rate on digit 3  : {det:.1%}")
print(f"  lift over chance           : {det / far:.1f}x")
```

This is a basic anomaly-detection setup without anomaly labels. In this example, the unusual class may still share many visual features with the training data, so the detector may miss some examples.

Use such a score to prioritize examples for review, not as an automatic decision unless it has been carefully validated. The threshold trades off missed cases against false alarms.
