This chapter builds a model that predicts a score from study time. We will write its prediction rule, measure its errors, and choose values for the rule from examples. The same pattern appears in larger models: define a function, measure its mistakes, and fit its parameters.

## A model makes predictions from parameters

The data was generated from a known relationship, with noise added. We can compare the values learned by a model with the values used to create the data.

```python run setup title="the data"
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)
n = 60
hours = rng.uniform(0, 10, n)                      # hours of revision
score = 12 + 7.5 * hours + rng.normal(0, 8, n)     # exam score, plus noise

plt.figure(figsize=(5, 3))
plt.scatter(hours, score, s=18)
plt.xlabel("hours revised"); plt.ylabel("exam score")
plt.tight_layout()
```

A linear model predicts a value from an input. For study hours, it has two parameters: a weight that controls the slope and a bias that shifts the line.

```python run title="the model"
def predict(x, w, b):
    """w: slope, b: intercept. Returns one prediction per element of x."""
    return w * x + b

predict(np.array([1.0, 5.0]), w=7.5, b=12.0)
```

The input data stays fixed during training. Training changes the parameters so the predictions fit the examples.

## Measure error with a loss

A loss function assigns one number to a set of predictions. A lower value means the predictions are closer according to that loss.

```python run title="mean squared error"
def mse(y_true, y_pred):
    return ((y_pred - y_true) ** 2).mean()

for w, b in [(7.5, 12.0), (5.0, 12.0), (7.5, 40.0), (0.0, 0.0)]:
    loss = mse(score, predict(hours, w, b))
    print(f"w={w:5.1f}  b={b:5.1f}   loss = {loss:9.2f}")
```

Mean squared error (MSE) squares each error and averages the results. Squaring prevents positive and negative errors from cancelling each other out. It also gives large errors more weight: an error of 10 contributes one hundred times as much as an error of 1.

Choosing a loss defines which errors matter most. MSE strongly penalizes large misses. If those misses are meaningful, that may be useful. If they are noisy measurements, mean absolute error may be a better choice. The right loss depends on the task.

## Fit by trying parameter values

One simple way to fit the model is to try many possible weights and biases, then keep the pair with the lowest loss. This is called grid search. It is practical when there are only a few parameters and a small search range.

```python run title="grid search"
ws = np.linspace(0, 15, 120)
bs = np.linspace(-20, 40, 120)
W, B = np.meshgrid(ws, bs)

# Broadcasting does all the work: (120,120,1) against (60,) -> (120,120,60)
preds  = W[..., None] * hours + B[..., None]
losses = ((preds - score) ** 2).mean(axis=-1)     # collapse the examples axis

i, j = np.unravel_index(losses.argmin(), losses.shape)
print(f"best on grid:  w={ws[j]:.3f}  b={bs[i]:.3f}   loss={losses[i, j]:.2f}")
print(f"truth:         w=7.500  b=12.000")
```

The best pair in the grid is close to the generating values, though it may not match them exactly. A finer grid would test more pairs.

The code uses broadcasting to evaluate many parameter pairs at once. It adds an axis so each pair can be compared with every example, then averages over the examples.

The loss surface shows the loss for each pair of parameters:

```python run title="the loss surface"
plt.figure(figsize=(5.2, 3.4))
plt.contourf(W, B, np.log(losses), levels=28, cmap="Blues_r")
plt.plot(ws[j], bs[i], "r*", markersize=13)
plt.xlabel("w (slope)"); plt.ylabel("b (intercept)")
plt.title("log loss surface"); plt.colorbar(label="log MSE")
plt.tight_layout()
```

Think of the parameters as coordinates and the loss as height. Training searches for a low point. For this two-parameter example, we can draw the surface. A large neural network has far more parameters, so its loss surface cannot be drawn this way.

Grid search becomes impractical as the number of parameters grows. If each of ten parameters had 120 possible values, the search would require 120 to the power of 10 evaluations. Neural networks often have thousands or millions of parameters, so they need more efficient fitting methods.

## Solve for the best fit directly

For a linear model with squared error, linear algebra gives a direct solution. This is called the normal equation.

```python run title="the normal equation"
X = np.column_stack([np.ones(n), hours])     # bias folded in as a column of 1s
theta = np.linalg.solve(X.T @ X, X.T @ score)
print(f"closed form:   b={theta[0]:.3f}  w={theta[1]:.3f}")
print(f"loss:          {mse(score, X @ theta):.3f}")
```

The example uses a column of ones so the bias can be included in the same parameter vector as the weights. In practice, use a linear solver rather than explicitly calculating a matrix inverse. Solving is usually faster and more numerically stable.

This solution is useful for small linear problems. Its cost grows quickly with the number of features, and the required matrix may be singular when features are redundant. More importantly, a direct solution is available only for certain model and loss combinations. Many models, including neural networks, need an iterative method. Chapter 5 introduces gradient descent.

## From regression to classification

Regression predicts a number. Classification predicts a category. For binary classification, a model can first produce a score and then convert it to a probability between 0 and 1.

```python run setup title="binary labels"
passed = (score > 50).astype(int)      # did they pass?

plt.figure(figsize=(5, 2.6))
plt.scatter(hours, passed, s=18, alpha=0.7)
plt.yticks([0, 1], ["fail", "pass"]); plt.xlabel("hours revised")
plt.tight_layout()
```

The sigmoid function performs that conversion:

```python run title="the sigmoid"
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

z = np.linspace(-8, 8, 200)
plt.figure(figsize=(5, 2.6))
plt.plot(z, sigmoid(z))
plt.axhline(0.5, ls=":", c="grey"); plt.axvline(0, ls=":", c="grey")
plt.title("sigmoid: any real number -> (0, 1)")
plt.tight_layout()
```

The sigmoid takes a score, sometimes called a logit, and returns a value between zero and one. A score of zero maps to 0.5; large positive and negative scores map close to one and zero.

A linear model followed by a sigmoid is called logistic regression. Despite its name, it is commonly used for classification. It is a useful first model for binary tasks.

Classification needs a loss that rewards useful probabilities. The next example compares squared error with binary cross-entropy:

```python run title="why not squared error for probabilities"
def bce(y, p):                       # binary cross-entropy
    p = np.clip(p, 1e-12, 1 - 1e-12) # never take log(0)
    return -(y * np.log(p) + (1 - y) * np.log(1 - p)).mean()

for p in [0.99, 0.9, 0.5, 0.1, 0.01]:
    print(f"true label 1, predicted {p:.2f}   "
          f"squared error {(1-p)**2:6.3f}   cross-entropy {bce(np.array([1]), np.array([p])):7.3f}")
```

When the true label is 1 and the model assigns a very low probability to it, the model is confidently wrong. Cross-entropy penalizes this more strongly than squared error. This encourages the model to avoid confident predictions that contradict the data.

MSE and cross-entropy can both be understood through maximum likelihood. If measurement noise is modelled with a normal distribution, maximizing the likelihood leads to squared error. If labels are modelled as Bernoulli outcomes, maximizing the likelihood leads to cross-entropy. The choice of loss reflects assumptions about the target and the errors.

Now fit logistic regression with scikit-learn:

```python run title="logistic regression, fitted"
from sklearn.linear_model import LogisticRegression

X1 = hours.reshape(-1, 1)                 # sklearn wants (n_samples, n_features)
clf = LogisticRegression().fit(X1, passed)
w, b = clf.coef_[0, 0], clf.intercept_[0]

grid = np.linspace(0, 10, 200)
plt.figure(figsize=(5, 2.8))
plt.scatter(hours, passed, s=18, alpha=0.6)
plt.plot(grid, sigmoid(w * grid + b), c="crimson")
plt.axhline(0.5, ls=":", c="grey")
plt.xlabel("hours revised"); plt.ylabel("P(pass)")
plt.title(f"P(pass) = sigmoid({w:.2f}·hours {b:+.2f})")
plt.tight_layout()
```

Scikit-learn expects features in a two-dimensional array: rows are examples and columns are features. Even a single feature must keep its column dimension. Reshaping a one-dimensional array is a common step.

The model returns probabilities. To turn a probability into a class, choose a threshold. The default is often 0.5, but the right threshold depends on the relative costs of false positives and false negatives.

## Practice: fit a model with two features

Use the normal equation to estimate house prices from area and bedroom count. Compare its error with a baseline that always predicts the average price.

```python run title="your turn"
rng = np.random.default_rng(7)
m = 200
sqm       = rng.uniform(30, 150, m)
bedrooms  = rng.integers(1, 5, m).astype(float)
price     = 40 + 3.2 * sqm + 18 * bedrooms + rng.normal(0, 25, m)

# 1. Build X of shape (200, 3): a column of ones, then sqm, then bedrooms.
# 2. Solve for theta with the normal equation.
# 3. Print the recovered coefficients against the truth (40, 3.2, 18).
# 4. Compute the MSE, and compare it to a baseline that always predicts
#    price.mean(). By what factor is the model better?

print("replace me")
```

One solution is shown below:

```python run
X = np.column_stack([np.ones(m), sqm, bedrooms])
theta = np.linalg.solve(X.T @ X, X.T @ price)
print("recovered:", theta.round(2), "   truth: [40.  3.2 18. ]")

model_mse    = ((X @ theta - price) ** 2).mean()
baseline_mse = ((price.mean() - price) ** 2).mean()
print(f"model    MSE {model_mse:8.1f}")
print(f"baseline MSE {baseline_mse:8.1f}   ({baseline_mse / model_mse:.0f}x worse)")
```

The estimated coefficients will not exactly match the values used to generate the data because noise was added. No fitting method can recover information that is absent from the observations.

Always compare a model with a baseline. An MSE value by itself is hard to interpret because it depends on the target's units and scale. Comparing it with a simple prediction gives the result a reference point.
