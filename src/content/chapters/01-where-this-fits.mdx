Start with a real task: classify handwritten digits. Run the first example. It trains a model on some labelled images and measures its accuracy on images kept aside for testing.

```python run setup title="fit a digit classifier"
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

digits = load_digits()                       # 1797 hand-written digits, 8x8 pixels
X_train, X_valid, y_train, y_valid = train_test_split(
    digits.data, digits.target, test_size=0.3, random_state=0)

model = LogisticRegression(max_iter=5000).fit(X_train, y_train)
print(f"accuracy on digits it has never seen: {model.score(X_valid, y_valid):.1%}")
```

The dataset contains small pictures and their correct labels. During training, the model sees pixels and labels. It adjusts its parameters to reduce mistakes. The test set gives us a separate check on examples it did not train on. An accuracy near 95% is a useful result for this small demonstration, but it does not mean the model understands handwriting or will work equally well on every writer.

## How machine learning differs

| Approach | What a person provides | What the computer produces |
|---|---|---|
| Ordinary programming | Rules and input | Output |
| Machine learning | Examples, feedback, and input | A fitted model |

In ordinary programming, a person writes the rules. In machine learning, a training process adjusts a model using examples and a measure of error. This is useful when the rules are hard to specify. A person can recognize a cat in many kinds of photos, but writing down every useful feature and exception is difficult. A model can learn patterns from labelled examples, though it can still fail on unfamiliar images.

## Core terms

**Artificial intelligence (AI)** is the broad field of building systems that perform tasks associated with human intelligence. The term dates to a 1956 workshop. Some AI systems use hand-written rules; others learn from data.

**Machine learning (ML)** is an approach within AI. A model is fitted to examples instead of having every rule written by hand. Logistic regression and decision trees are ML methods. They do not require neural networks.

**Deep learning** is machine learning that uses neural networks with many layers. It is useful for tasks such as image, audio, and language processing, where useful patterns can be difficult to describe directly.

A **model** is a function with parameters set by training. The variable named model above holds one. Other software can call it to make predictions on new examples.

Product descriptions often use “AI” without saying which method is involved. Ask what the system does and what it learned from data; the label alone tells you little.

Three more terms will appear often:

- **Training** is the process of fitting a model to examples.
- **Inference** is using a fitted model to make a prediction.
- **Parameters**, also called weights, are the values training adjusts.

## A model is a function with numbers

The digit classifier stores one set of weights for each digit. Together, those weights and offsets make up 650 learned numbers.

```python run title="a model is just numbers"
w = model.coef_          # the learned weights
b = model.intercept_     # the learned offsets
print("weights:", w.shape, " offsets:", b.shape)
print("total learned numbers:", w.size + b.size)
```

For an image, the model combines its pixels with each digit's weights and adds an offset. This gives one score per digit. It predicts the digit with the highest score. The next example performs that calculation directly:

```python run title="inference, from scratch"
import numpy as np

image = X_valid[0]                    # one 8x8 digit, flattened to 64 numbers
scores = image @ w.T + b              # ten scores, one per digit
print("scores :", np.round(scores, 1))
print("predicted:", scores.argmax(), " actual:", y_valid[0])
```

That calculation is inference. A fitted model can make predictions with a small number of operations. Training is the step that found the parameters, and it usually takes more work.

## What the weights represent

Each row of the weight matrix corresponds to one digit. A dot product combines an image's pixels with one row of weights to produce a score. The visualization below shows those weights as small images.

```python run title="what the model learned"
import matplotlib.pyplot as plt
fig, axes = plt.subplots(2, 5, figsize=(7, 3))
for digit, ax in enumerate(axes.flat):
    ax.imshow(w[digit].reshape(8, 8), cmap="RdBu_r")
    ax.set_title(str(digit), fontsize=9); ax.axis("off")
plt.tight_layout()
```

Red weights raise a digit's score when the corresponding pixel is bright. Blue weights lower it. For example, the weights for zero tend to favour a ring and give lower scores to ink near the centre.

This classifier uses one template per digit. It cannot capture every variation in handwriting, such as sevens with and without a crossbar. A neural network can combine simpler features in more flexible ways; Chapter 8 introduces that approach.

## Why machine learning became more useful

Many machine-learning ideas are decades old. The perceptron, an early artificial neuron, was built in 1958. Backpropagation became widely known in 1986. Convolutional networks were used to read handwritten cheques in the early 1990s, and LSTMs for sequence data appeared in 1997. Three changes later made larger models practical.

**More data.** Models need examples. ImageNet, assembled from 2007 to 2009, contained more than 14 million labelled images. The internet made images easier to collect, and online workers helped label them.

**More computing power.** Training requires many matrix operations. Graphics processing units (GPUs), designed to draw images quickly, can perform many of these operations in parallel. GPUs made neural-network experiments faster and allowed researchers to try larger models.

**Better training methods.** Improvements to initial weights, activation functions, regularisation, and optimisation made deep networks easier to train. You will meet these ideas later.

These changes came together in 2012, when AlexNet won a major image-recognition competition. Its error rate was 15.3%, compared with 26.2% for the next-best entry. The result led many researchers to focus on deep learning. Progress often happens this way: an older idea becomes practical when data, computing power, and training methods improve together.

## When a model is not the right tool

Machine learning is not the best choice for every problem.

- **The rules are clear.** Tax calculations follow explicit rules. Implement them directly so the result is predictable and explainable.
- **A mistake could cause serious harm.** Models can be wrong and may not explain a prediction. Use appropriate safeguards and keep qualified people involved in high-stakes decisions.
- **You do not have enough relevant data.** A small or unrepresentative sample may not support a reliable model. Collect better data or choose another method.
- **A simple method already works.** Start with a clear baseline, such as a count, average, or fixed rule. Keep a more complex model only if it improves the result enough to justify its cost.

Before training, check that the data can answer the question you care about. [Chapter 3](/learn/03-the-shape-of-problems/) explains how to frame a problem for machine learning.

Machine-learning projects answer three separate questions:

1. **What feedback is available?** Examples include labels, patterns in unlabelled data, or rewards from actions.
2. **What kind of model will make predictions?** Examples include a linear model, a tree, or a neural network.
3. **How will the model be fitted and checked?** This includes its loss, training method, and evaluation data.

These choices are related, but they are not the same. A tree or neural network can use different kinds of feedback. Keeping the questions separate makes it easier to compare methods.
