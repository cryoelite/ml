A sequence has order: each token's position matters. Attention lets each position compare its representation with other positions and combine information from them. This chapter builds attention from its basic operations, then assembles a transformer block.

## From recurrent networks to attention

A recurrent network reads a sequence one step at a time and carries a hidden state forward.

```python run setup title="an RNN, in five lines"
import numpy as np, matplotlib.pyplot as plt

def rnn(inputs, W_x, W_h, h0):
    h = h0
    states = []
    for x in inputs:                       # strictly one at a time
        h = np.tanh(x @ W_x + h @ W_h)
        states.append(h)
    return np.array(states)

rng = np.random.default_rng(0)
seq = rng.normal(size=(12, 4))
states = rnn(seq, rng.normal(size=(4, 8)) * .5, rng.normal(size=(8, 8)) * .5, np.zeros(8))
print("processed", len(states), "steps sequentially; final state", states[-1].round(2))
```

This design can make long-range information hard to preserve in one hidden state. It also limits parallelism: the next step depends on the previous step. Attention allows positions to exchange information directly and processes many positions in parallel during training.

## Build attention

For each position, create three vectors:

- A **query** describes what the position is looking for.
- A **key** describes what the position can match.
- A **value** contains the information the position can pass on.

Compare queries with keys to calculate scores. Convert each row of scores to weights with softmax, then use those weights to combine the values.

```python run title="attention, from nothing"
def softmax(z, axis=-1):
    z = z - z.max(axis=axis, keepdims=True)      # keeps exponentials in range
    e = np.exp(z)
    return e / e.sum(axis=axis, keepdims=True)

def attention(Q, K, V, mask=None):
    d_k = Q.shape[-1]
    scores = Q @ K.T / np.sqrt(d_k)              # (n_q, n_k) — every query vs every key
    if mask is not None:
        scores = np.where(mask, scores, -np.inf) # forbidden positions get zero weight
    weights = softmax(scores)                    # each row sums to 1
    return weights @ V, weights                  # weighted average of the values

n, d = 5, 8
rng = np.random.default_rng(0)
Q, K, V = (rng.normal(size=(n, d)) for _ in range(3))
out, w = attention(Q, K, V)
print("output shape ", out.shape)
print("weight rows sum to 1:", np.allclose(w.sum(-1), 1))
```

The attention weights show how much each position uses information from other positions:

```python run title="what the weights mean"
plt.figure(figsize=(4.2, 3.4))
plt.imshow(w, cmap="Blues", vmin=0)
plt.colorbar(label="attention weight")
plt.xlabel("key position (looked at)"); plt.ylabel("query position (looking)")
plt.title("row i = how position i distributes its attention")
plt.tight_layout()
```

Each row is a distribution over positions. Larger weights mean that position contributes more to the weighted sum.

## Self-attention

In self-attention, the queries, keys, and values are learned projections of the same sequence.

```python run title="self-attention on a real-ish sequence"
d_model, d_head = 16, 16
X = rng.normal(size=(6, d_model))                # 6 tokens, 16 dims each

W_q, W_k, W_v = (rng.normal(size=(d_model, d_head)) * 0.3 for _ in range(3))
Q, K, V = X @ W_q, X @ W_k, X @ W_v
out, w = attention(Q, K, V)

print("input ", X.shape, "-> output", out.shape, " (same shape: it is a mixer, not a resizer)")
print("\nposition 0 attends to:", w[0].round(2))
```

The projections are learned during training. Attention itself is a weighted combination of values, with the weights determined by query-key similarity.

The score is divided by the square root of the key dimension before softmax. Without this scaling, dot products can become large as the dimension grows. Large scores can make softmax too concentrated and its gradients small.

```python run title="see it happen"
for d_k in [4, 64, 512]:
    q = rng.normal(size=(1000, d_k)); k = rng.normal(size=(1000, d_k))
    raw = (q * k).sum(-1)
    print(f"d_k={d_k:4d}   unscaled score std {raw.std():7.2f}   "
          f"scaled {(raw / np.sqrt(d_k)).std():.2f}")
```

The scaling keeps the scores at a useful range at initialization. Its effect depends on the model and training setup, but it helps stabilize attention calculations.

## Causal masking

For next-token prediction, each position must not use tokens that come later in the sequence. A causal mask sets those future scores to negative infinity before softmax, giving them zero weight.

```python run title="the mask that makes GPT possible"
n = 6
causal = np.tril(np.ones((n, n), dtype=bool))    # True on and below the diagonal
print(causal.astype(int))

X = rng.normal(size=(n, d_model))
Q, K, V = X @ W_q, X @ W_k, X @ W_v
_, w_causal = attention(Q, K, V, mask=causal)

plt.figure(figsize=(4, 3.2))
plt.imshow(w_causal, cmap="Blues", vmin=0)
plt.title("causal attention: nothing looks right of the diagonal")
plt.xlabel("key"); plt.ylabel("query"); plt.colorbar()
plt.tight_layout()
```

Without a causal mask, every position can use the full input. With the mask, position i can attend only to positions at or before i. This is the attention pattern used by autoregressive language models. Encoder models commonly use unmasked attention when the full input is available.

## Multiple heads

A single attention operation learns one set of relationships. Multi-head attention uses several projections in parallel, then combines their outputs.

```python run title="multi-head attention"
def multihead(X, Wq, Wk, Wv, Wo, n_heads, mask=None):
    n, d_model = X.shape
    d_head = d_model // n_heads
    heads = []
    for h in range(n_heads):
        sl = slice(h * d_head, (h + 1) * d_head)
        out, _ = attention(X @ Wq[:, sl], X @ Wk[:, sl], X @ Wv[:, sl], mask)
        heads.append(out)
    return np.concatenate(heads, axis=-1) @ Wo   # mix the heads back together

d_model, n_heads = 32, 4
X = rng.normal(size=(8, d_model))
Wq, Wk, Wv, Wo = (rng.normal(size=(d_model, d_model)) * 0.2 for _ in range(4))
print("multi-head output:", multihead(X, Wq, Wk, Wv, Wo, n_heads).shape)
print(f"{n_heads} heads x {d_model // n_heads} dims = {d_model}, same as the input")
```

The model divides the representation across heads, then concatenates the head outputs. Different heads can learn different patterns, though their roles are learned rather than assigned by hand.

## Add position

Attention without position information is permutation-equivariant: if the input order changes, the outputs change in the same way. It does not know that one token came before another.

```python run title="attention cannot see order"
X = rng.normal(size=(5, d_model))
perm = np.array([3, 1, 4, 0, 2])
a = multihead(X, Wq, Wk, Wv, Wo, 4)
b = multihead(X[perm], Wq, Wk, Wv, Wo, 4)
print("permuting the input just permutes the output:", np.allclose(a[perm], b))
```

Language needs positional information. One approach adds sine and cosine values for each position to the token representations:

```python run title="sinusoidal positional encoding"
def positional_encoding(n_positions, d_model):
    pos = np.arange(n_positions)[:, None]
    i = np.arange(d_model)[None, :]
    angle = pos / np.power(10000, (2 * (i // 2)) / d_model)
    pe = np.zeros((n_positions, d_model))
    pe[:, 0::2] = np.sin(angle[:, 0::2])
    pe[:, 1::2] = np.cos(angle[:, 1::2])
    return pe

pe = positional_encoding(64, 32)
plt.figure(figsize=(5.5, 3))
plt.imshow(pe.T, cmap="RdBu_r", aspect="auto")
plt.xlabel("position in sequence"); plt.ylabel("embedding dimension")
plt.title("each position gets a unique signature"); plt.colorbar()
plt.tight_layout()
```

Modern transformers use several positional schemes, including rotary position embeddings. These can encode relative position in attention scores. Their behaviour on longer sequences depends on the method and how the model was trained.

## Assemble a transformer block

A transformer block combines self-attention, residual connections, normalization, and a feed-forward network.

```python run title="a transformer block, assembled"
def layer_norm(x, eps=1e-5):
    mu = x.mean(-1, keepdims=True)
    sd = x.std(-1, keepdims=True)
    return (x - mu) / (sd + eps)

def transformer_block(X, params, n_heads=4, mask=None):
    # Apply attention and the feed-forward layer with residual connections.
    h = X + multihead(layer_norm(X), *params["attn"], n_heads, mask)
    ff = layer_norm(h) @ params["W1"]
    ff = np.maximum(0, ff) @ params["W2"]            # position-wise MLP
    return h + ff

d_model, d_ff = 32, 128
params = {
    "attn": [rng.normal(size=(d_model, d_model)) * .2 for _ in range(4)],
    "W1": rng.normal(size=(d_model, d_ff)) * .2,
    "W2": rng.normal(size=(d_ff, d_model)) * .2,
}
X = rng.normal(size=(10, d_model))
out = transformer_block(X, params, mask=np.tril(np.ones((10, 10), dtype=bool)))
print("block output:", out.shape, " — same shape in, same shape out")
print("so you can stack it:", transformer_block(out, params).shape)
```

Attention mixes information across positions. The feed-forward network transforms each position's representation. Residual connections provide a direct path for information and gradients. Normalization helps keep activations at usable scales.

Stacking blocks builds a transformer. The architecture is repeated; size, data, training, and engineering distinguish small examples from large models.

## The cost of attention

Standard attention forms scores between every pair of positions. With sequence length n, the attention matrix has n squared entries.

```python run title="quadratic"
print(f"{'sequence':>10s} {'attention matrix':>18s} {'float32 memory':>16s}")
for n in [512, 2_048, 8_192, 128_000, 1_000_000]:
    cells = n * n
    print(f"{n:>10,} {cells:>18,} {cells * 4 / 1e9:>13,.1f} GB")
```

Doubling sequence length roughly quadruples the attention-score memory and computation in this formulation. Implementations such as FlashAttention reduce memory traffic and avoid storing the full matrix, while preserving exact attention. Other methods restrict which positions can interact or approximate the calculation.

With all scores equal, softmax assigns equal weight to every allowed position. In a causal model, each position computes an average of the available values.

```python run
# 1. Uniform attention
n = 5
uniform = softmax(np.where(np.tril(np.ones((n, n), dtype=bool)), 0.0, -np.inf))
print(np.round(uniform, 3))
```

A query aligned with one key produces a larger score for that position, so the attention weights concentrate there. This shows how training can learn to retrieve information from earlier positions.

Some trained models develop heads that copy patterns from previous positions. Researchers have identified such circuits in particular models, but they are one part of a larger mechanism; there is no single complete explanation of in-context learning.

```python run
# 2. Making position 1 look at position 0
d = 4
K = np.array([[1., 0, 0, 0],      # position 0's key
              [0., 1, 0, 0]])     # position 1's key
Q = np.array([[0., 0, 0, 0],
              [9., 0, 0, 0]])     # position 1 queries hard for "direction 0"
_, w = attention(Q, K, np.eye(2), mask=np.tril(np.ones((2, 2), dtype=bool)))
```

Residual connections add the block input to the transformed output. They help information and gradients pass through deep stacks.

```python run
# 3. Residuals
def block_no_residual(X, params, n_heads=4):
    h = multihead(layer_norm(X), *params["attn"], n_heads)
    return np.maximum(0, layer_norm(h) @ params["W1"]) @ params["W2"]

for label, fn in [("with residual", transformer_block), ("without", block_no_residual)]:
    x = rng.normal(size=(10, d_model))
    mags = []
    for _ in range(6):
        x = fn(x, params)
        mags.append(np.abs(x).mean())
    print(f"{label:15s} activation magnitude by depth: {np.round(mags, 4)}")
```
