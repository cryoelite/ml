## Python basics

A **variable** gives a name to a value. It can hold a number or a list of several numbers. Assigning a new value changes what the name refers to.

A **list** stores values in order. Python starts list positions at zero, so the first item is at position zero.

A **function** groups steps under a name. You give it inputs; it returns a result:

```python run title="a function"
def average(numbers):
    return sum(numbers) / len(numbers)

average([7, 9, 4])
```

The keyword def begins a function. Indented lines are part of its body, and return gives back the result. Python uses indentation to mark blocks, so spaces affect how the program runs.

The next example combines several common features: a default argument, a keyword-only argument, a loop, a formatted string, and a docstring.

```python run title="the shape of it"
def train(examples, lr=0.01, *, verbose=False):
    """A note about what this does. Python keeps it and can show it to you."""
    total = 0.0
    for i, (x, y) in enumerate(examples):
        total += (x - y) ** 2
        if verbose:
            print(f"  {i}: running total {total:.2f}")
    return total / len(examples)

train([(1.0, 0.8), (2.0, 2.4)], verbose=True)
```

The argument lr has a default value. The asterisk means verbose must be passed by name. A formatted string can insert values into text. The enumerate function pairs each item with its position, and tuple unpacking assigns those values to separate names. Python uses two asterisks for powers and a slash for division that can return a decimal.

### Build lists and dictionaries

A list comprehension creates a list from a rule. Read it as: “for each item, keep it if this condition is true, then make this value.”

```python run
xs = list(range(10))
squares = [x * x for x in xs if x % 2 == 0]
lookup  = {name: i for i, name in enumerate("abc")}
squares, lookup
```

Curly braces make a dictionary of key-value pairs. Parentheses can make a generator, which produces values as they are requested instead of storing them all at once. Comprehensions are useful when they remain easy to read. If the rule gets complicated, use a regular loop.

### Group related values

A class groups related data and behaviour. A dataclass is a small helper that creates common methods for a class that mainly stores values.

```python run
from dataclasses import dataclass

@dataclass
class Config:
    lr: float = 1e-3
    epochs: int = 5

cfg = Config(lr=0.01)
print(cfg)
print({**cfg.__dict__, "epochs": 10})   # ** spreads a dict
```

A decorator is a function applied to a definition. Here, the dataclass decorator creates an initializer and readable display for the settings. The double-star operator can unpack a dictionary into named arguments. Libraries often use this pattern for optional settings.

Two more Python features appear often. A with statement manages a resource and closes it reliably, and pathlib.Path builds file paths with the slash operator.

## Work with NumPy arrays

A NumPy array stores numbers of one type in a rectangular shape. Its shape tells you how many values it has along each dimension.

```python run setup title="arrays, not lists"
import numpy as np

a = np.array([[1., 2., 3.],
              [4., 5., 6.]])
print(a.shape, a.dtype, a.ndim, a.size)
a * 2 + 1
```

This array has two rows and three columns. Multiplying it by 2 and adding 1 applies those operations to every value. This is called a vectorized operation: you describe the operation for the whole array rather than writing a Python loop.

Vectorized operations are usually faster because NumPy runs the loops in compiled code and stores array values in a compact layout. The example compares a Python loop with a NumPy operation. The timing depends on your computer, so focus on the relative scale rather than an exact number.

```python run title="why the loop has to go"
import time

n = 300_000
py_list = list(range(n))
np_arr  = np.arange(n)

t = time.perf_counter()
_ = [x * 2 for x in py_list]
py_ms = (time.perf_counter() - t) * 1000

t = time.perf_counter()
_ = np_arr * 2
np_ms = (time.perf_counter() - t) * 1000

print(f"python list : {py_ms:7.2f} ms")
print(f"numpy array : {np_ms:7.2f} ms   ({py_ms / np_ms:.0f}x faster)")
```

Arrays can have more than one shape while keeping the same values. The reshape operation changes how those values are arranged. Use shape to inspect dimensions when an operation fails.

```python run
a = np.arange(12)
print("flat      ", a.shape)
print("as 3x4    ", a.reshape(3, 4).shape)
print("as ?x2    ", a.reshape(-1, 2).shape)     # -1 means 'you work it out'
print("transposed", a.reshape(3, 4).T.shape)
```

The value -1 tells NumPy to infer that dimension from the number of values. A transpose, written as .T, swaps rows and columns.

### Work with dimensions

An axis is one dimension of an array. When an operation reduces an array, such as sum, the axis you name is the dimension that disappears.

```python run
m = np.arange(6).reshape(2, 3)
print(m)
print("sum(axis=0) collapses the 2 ->", m.sum(axis=0), m.sum(axis=0).shape)
print("sum(axis=1) collapses the 3 ->", m.sum(axis=1), m.sum(axis=1).shape)
```

For a two-dimensional array, axis 0 reduces down the rows and leaves one result per column. Axis 1 reduces across each row. In a dataset, rows often represent examples and columns represent features, so mean(axis=0) computes the average of each feature.

### Use broadcasting

Broadcasting lets NumPy combine arrays with different shapes without copying values. Compare dimensions from right to left: each pair must match or one dimension must be 1.

```python run
rows = np.arange(3).reshape(3, 1)   # shape (3, 1)
cols = np.arange(4)                 # shape (4,)
print(rows + cols)                  # -> (3, 4)
```

Here, a column of three values plus a row of four values produces a 3-by-4 result. NumPy repeats the smaller arrays logically across the result.

A common use is adding one bias value per feature to a batch of examples:

```python run
batch = np.ones((32, 4))     # 32 examples, 4 features
bias  = np.array([10., 20., 30., 40.])   # one per feature
(batch + bias).shape, (batch + bias)[0]
```

The same four bias values are added to each of the 32 rows. Neural-network layers use this pattern.

Broadcasting can also create silent bugs. If predictions have shape (3,) and labels have shape (3, 1), subtraction produces a 3-by-3 array instead of three errors.

```python run title="the bug you will write"
pred  = np.array([1., 2., 3.])            # shape (3,)
truth = np.array([[1.], [2.], [3.]])      # shape (3, 1)  <- a stray column
err = pred - truth
print("expected shape (3,), got", err.shape, "and", err.size, "numbers")
print(err)
```

The result is valid arithmetic, so NumPy does not raise an error. Check array shapes when a result looks surprising, especially before computing a loss.

### Common array operations

The next example shows matrix multiplication, a feature average, a comparison, and Boolean indexing.

```python run
rng = np.random.default_rng(0)
X = rng.normal(size=(5, 3))
w = rng.normal(size=3)

print("X @ w        ", (X @ w).shape, "  <- matrix multiply, the workhorse")
print("X.mean(0)    ", X.mean(axis=0).round(2))
print("X > 0        ", (X > 0).sum(), "positive entries")
print("X[X > 0][:3] ", X[X > 0][:3].round(2), " <- boolean indexing")
```

Use @ for matrix multiplication and * for element-by-element multiplication. Boolean indexing selects values where a condition is true.

A useful example: comparing predictions with labels produces true and false values. Their mean is the fraction of correct predictions, because true and false behave like 1 and 0 in this calculation.

Use NumPy's random number generator with a fixed seed when you want to reproduce an experiment. Reproducibility helps you tell whether a change improved the result or randomness caused the difference.

### Views and copies

A slice of a NumPy array can be a **view**: a new way to access the same underlying values. Changing a view can therefore change the original array.

```python run title="views alias, copies do not"
a = np.arange(6)
view = a[2:5]        # a VIEW into a's memory
view[0] = 999
print("a is now", a)

b = np.arange(6)
copy = b[2:5].copy() # explicit copy
copy[0] = 999
print("b is still", b)
```

A copy stores its own values, so edits do not change the source. Basic slicing usually returns a view; Boolean and integer-array indexing return copies. Reshape returns a view when the existing memory layout allows it. When you need an independent array, use the copy method.

## Inspect tables with pandas

A pandas DataFrame is a table with named columns. It is useful for loading data, checking values, and selecting rows and columns.

```python run
import pandas as pd

df = pd.DataFrame({
    "hours":  [1.0, 2.0, 3.5, 4.0, 5.5, 6.0],
    "passed": [0, 0, 0, 1, 1, 1],
    "cohort": ["a", "a", "b", "b", "a", "b"],
})
df.head(3)
```

Check the column types and look at summaries grouped by category:

```python run
print(df.dtypes.to_dict())
print()
print(df.groupby("cohort")["passed"].mean())
```

The groupby operation splits rows into groups and calculates a summary for each one. Before training, check how the target varies across important features. If the average target is nearly the same for every value of a feature, that feature may contain little predictive information.

Use df.loc to select rows and columns by name, and df.iloc to select them by position. A column's values property gives you its underlying NumPy array.

## Other libraries you may see

SciPy adds scientific tools such as optimization, statistics, sparse matrices, and signal processing to NumPy.

Polars is another library for working with tables. It has a similar role to pandas and is designed to handle larger datasets efficiently. This course uses pandas because it appears in many tutorials and examples.

JAX provides a NumPy-like interface along with automatic differentiation and ways to compile or transform functions for accelerators. It is common in research.

The einsum operation describes array calculations by naming their dimensions. It can replace matrix multiplication, though the notation is more general:

```python run title="einsum, gently"
import numpy as np
A = np.arange(6).reshape(2, 3)
B = np.arange(12).reshape(3, 4)

print("normal :", (A @ B).shape)
print("einsum :", np.einsum("ij,jk->ik", A, B).shape)
```

In ij,jk->ik, the repeated index j is summed over; the result keeps dimensions i and k. This notation becomes useful when an operation involves many dimensions, as in attention layers.
