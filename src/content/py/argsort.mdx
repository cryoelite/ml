signature: 'np.argsort(a)  ->  indices'
example: |-
  scores = np.array([0.2, 0.9, 0.5])
  order = np.argsort(scores)[::-1]     # descending
  order, scores[order]
output: '(array([1, 2, 0]), array([0.9, 0.5, 0.2]))'
rust: "Sort indices by their corresponding values when you need to keep other arrays aligned."

---
Argsort returns the indices that would sort an array. Apply those indices to related arrays to keep predictions, labels, or IDs aligned.

Use a reversed index order for descending sort. For a large array where you only need the top few values, argpartition can avoid sorting every element.
