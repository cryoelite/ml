A train/test split holds back data to evaluate a model on examples it did not train on. A fixed random state makes the split repeatable. Stratification can preserve class proportions in both sets.

Random splitting is not suitable when rows are related or ordered, such as repeated users or future prediction. Split by group or time when that matches deployment. See [Generalisation](/learn/06-generalisation/).
