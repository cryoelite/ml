Prefer `default_rng` over the legacy `np.random.seed` global: it gives you an
object you can pass around, which makes it obvious which code consumes
randomness.

Seeding does not guarantee identical results across machines, library versions
or GPU kernels. It guarantees that *your* run, on *your* machine, repeats —
which is enough to tell a real improvement from noise.
