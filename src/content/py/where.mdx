signature: 'np.where(condition, if_true, if_false)'
example: |-
  x = np.array([-2., 5., -1., 3.])
  np.where(x > 0, x, 0.0)          # this is ReLU
output: 'array([0., 5., 0., 3.])'
rust: "Select values elementwise using a condition."
docs: 'https://numpy.org/doc/stable/reference/generated/numpy.where.html'

---
NumPy’s where selects values based on a boolean condition. The condition and the two choices can broadcast to a shared shape.

With one argument, where returns the indices where the condition is true. Use nonzero if you want to make that intent clearer.
