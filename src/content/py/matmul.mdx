The `@` operator was added to Python in 3.5 for exactly this purpose, after
the scientific community argued that `A * B` meaning two different things in
two different libraries was costing real money in real bugs.

Read `(n, k) @ (k, m) -> (n, m)` as: the shared `k` is summed away. If you
remember only one shape rule, remember that one — the whole of deep learning
is stacks of it.
