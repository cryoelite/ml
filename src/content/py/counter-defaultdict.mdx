`Counter` counts things and sorts them for you. `most_common(k)` is the method
you will actually use, and it is how the byte-pair encoder in
[chapter 14](/learn/14-llms/) finds the most frequent adjacent pair.

`defaultdict(list)` gives every missing key a fresh empty list on first access,
so grouping becomes one line instead of three:

```
groups = defaultdict(list)
for item in items:
    groups[item.key].append(item)
```

The trap worth knowing: **merely reading a missing key from a `defaultdict`
creates it.** So `if d[k]:` silently inserts `k`, and a dictionary you only meant
to query quietly grows. Use `d.get(k)` when you are asking rather than building.

`Counter` also does arithmetic — `a + b` merges counts, `a - b` subtracts — which
is occasionally exactly what you want and easy to forget exists.
