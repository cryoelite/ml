Counter counts values and can return the most common ones. defaultdict creates a default value when a missing key is accessed; defaultdict(list) is useful for grouping items.

```
groups = defaultdict(list)
for item in items:
    groups[item.key].append(item)
```

Reading a missing key from defaultdict creates that key. Use get when you only want to check whether a value exists. Counter can also add or subtract count collections.
