title: 'slicing'

summary: "Select a sequence using start, stop, and step indices."

example: |-
  xs = [0, 1, 2, 3, 4, 5]
  xs[1:4], xs[-2:], xs[::2]
output: '([1, 2, 3], [4, 5], [0, 2, 4])'
rust: "Python list slices copy; basic NumPy slices usually return views into the same data."
rustCode: |-
  let xs = vec![0, 1, 2, 3, 4, 5];
  let a = &xs[1..4];   // borrow, not a copy
docs: 'https://docs.python.org/3.14/library/functions.html#slice'

---
Python slices use a start index and a stop index; the stop is excluded. Thus a slice from a to b has length b-a.

Basic NumPy slices usually return views into the original array, while list slices create a new list. Changes to a view can affect the source array.
