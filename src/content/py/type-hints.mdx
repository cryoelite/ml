Type hints describe the values a function expects and returns. Python does not enforce them at runtime, but editors and static type checkers can use them.

Type hints do not usually describe array dimensions. Add a short comment when the expected shape matters.

```python
def forward(x):          # x: (batch, features)
    return x @ self.w    # -> (batch, out)
```
