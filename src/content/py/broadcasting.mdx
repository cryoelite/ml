example: |-
  a = np.arange(3).reshape(3, 1)   # (3,1)
  b = np.arange(4)                 # (4,)
  (a + b).shape
output: '(3, 4)'

---
Broadcasting lets arrays with compatible shapes work together. Dimensions are compatible when they match or one of them is 1; missing leading dimensions are treated as 1.

For example, adding a vector with shape (10,) to an array with shape (32, 10) adds the vector to each row. Broadcasting can also create an unintended larger result. If a calculation looks wrong, print the shapes.
