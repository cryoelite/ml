Concatenate joins arrays along an axis that already exists. Stack adds a new axis.

For example, concatenating two arrays with shape (2, 3) along axis 0 gives shape (4, 3). Stacking them gives shape (2, 2, 3). PyTorch provides analogous cat and stack operations.
