  p = np.array([0.0, 0.5, 1.0])
  -np.log(np.clip(p, 1e-12, 1 - 1e-12))   # safe cross-entropy
output: 'array([2.76310211e+01, 6.93147181e-01, 1.00000008e-12])'
rust: "Use clamp to limit one value; array libraries apply it elementwise."

Clipping limits values to a chosen range. It can keep probabilities away from zero before taking a logarithm, or cap a gradient before an update.

Clipping can prevent numerical problems, but it may also hide an upstream issue. If model outputs need to be clipped to be meaningful, check whether the target or model is defined appropriately.
