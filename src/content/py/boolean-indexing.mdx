---
title: 'boolean indexing'
lib: 'numpy'
summary: "Select array elements using a boolean mask."
signature: 'a[mask]   |   a[a > 0]   |   a[mask] = 0'
example: |-
  a = np.array([-2, 5, -1, 3])
  a[a > 0], (a > 0).mean()
output: '(array([5, 3]), 0.5)'
rust: "Filter values with a condition. NumPy masks can also be combined or used for assignment."
rustCode: 'let kept: Vec<i32> = v.iter().copied().filter(|&x| x > 0).collect();'
docs: 'https://numpy.org/doc/stable/user/basics.indexing.html#boolean-array-indexing'
docsLabel: 'Indexing docs ↗'
---
A comparison creates a boolean array. The mean of booleans is the fraction that are true, so it can be used to calculate accuracy.

Combine array masks with & and |. Use parentheses around comparisons, and do not use Python’s and or or with NumPy arrays.
