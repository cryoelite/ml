---
title: "list comprehension"
summary: "Build a list by transforming or filtering an iterable."
signature: "[expr for item in iterable if condition]"
example: "squares = [x * x for x in range(6) if x % 2 == 0]"
output: "[0, 4, 16]"
rust: "A list comprehension is similar to iterator filter and map followed by collect."
rustCode: "let squares: Vec<i32> = (0..6).filter(|x| x % 2 == 0).map(|x| x * x).collect();"
docs: "https://docs.python.org/3/tutorial/datastructures.html#list-comprehensions"
lib: "stdlib"
since: "Python 2.0"
---
A list comprehension builds a list from an iterable, optionally applying a transformation or filter.

Use it for short, readable operations. A regular loop is clearer when the logic has several steps or side effects.
