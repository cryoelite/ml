Shuffle the *indices*, then index with them. That way `X[order]` and `y[order]`
stay aligned, which they would not if you shuffled each independently — an
alignment bug that produces a model training on randomly paired inputs and labels
and no error message at all.

Reshuffling between epochs matters more than it sounds. Without it, mini-batches
are the same every pass, so the gradient noise repeats and stops being the
useful exploration described in
[chapter 5](/learn/05-how-learning-happens/). It becomes a fixed bias instead.

`shuffle` mutates in place; `permutation` returns a new array. Prefer
`permutation` on indices — it composes better and never surprises you by
modifying data you still needed.
