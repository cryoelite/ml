title: 'the axis argument'
lib: 'numpy'
summary: "Choose which dimension an array operation reduces."
signature: 'a.sum(axis=0)   |   a.mean(axis=1)   |   a.argmax(axis=-1)'
example: |-
  a = np.arange(6).reshape(2, 3)
  a.sum(axis=0), a.sum(axis=1)
output: '(array([3, 5, 7]), array([ 3, 12]))'
rust: "An axis reduction is like applying an operation across one level of a nested array."
docs: 'https://numpy.org/doc/stable/reference/generated/numpy.sum.html'
docsLabel: 'numpy.sum ↗'
---
The axis argument names the dimension an operation reduces. For an array with shape (2, 3), sum along axis 0 returns a result with shape (3,), while axis 1 returns shape (2,).

In a batch of predictions, axis -1 is often the class dimension. Use keepdims=True when the reduced result needs to broadcast against the original array.
