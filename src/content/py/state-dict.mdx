`model.state_dict()` returns an ordinary dict mapping parameter names to tensors.
It contains no code, no class definitions and no import paths — which is exactly
why it is the thing to save.

You *can* pickle the whole model object with `torch.save(model, path)`. Don't. It
records the module path of your class, so renaming a file or reorganising a
package breaks every checkpoint you ever wrote. Loading it also executes arbitrary
code, which makes an untrusted checkpoint a genuine security problem — pass
`weights_only=True` when loading anything you did not produce.

Two practical additions. Save the optimiser's state dict alongside the model if
you want to resume training, because Adam's moment estimates are state you would
otherwise lose. And save a version string and the hyperparameters in the same
file — the checkpoint that cannot tell you what produced it is the one you find
in eight months.
