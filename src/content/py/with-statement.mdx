  {
      let f = File::open("data.csv")?;  // closed when the block ends

A with statement runs a block inside a context manager. The context manager can set up a resource or temporary behavior, then restore or close it when the block ends.

In PyTorch, torch.no_grad() is commonly used this way to disable gradient recording for a block.
