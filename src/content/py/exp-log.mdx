Exponentials and logarithms appear in softmax and likelihood calculations. Directly exponentiating a large score can overflow, so a stable softmax subtracts the largest score before exponentiating. The result is unchanged because the same factor cancels from numerator and denominator.

```python
z = z - z.max()
p = np.exp(z) / np.exp(z).sum()
```
