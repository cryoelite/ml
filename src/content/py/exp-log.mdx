The snippet above is a softmax, and it is also numerically dangerous:
`np.exp(1000)` is `inf`, and `inf / inf` is `nan`. The standard fix is to
subtract the maximum first, which cannot change the answer because
$e^{z-c}/\sum e^{z-c}$ equals $e^{z}/\sum e^{z}$:

```python
z = z - z.max()
p = np.exp(z) / np.exp(z).sum()
```

Every real implementation does this. It is the single most common piece of
defensive numerics in machine learning.
