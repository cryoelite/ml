  import numpy as np, matplotlib.pyplot as plt
  x = np.linspace(-6, 6, 200)
  plt.plot(x, 1 / (1 + np.exp(-x)))
  plt.title('sigmoid')
  plt.show()

Matplotlib’s pyplot interface creates figures and plots with a small number of commands. In notebooks, the current figure is often displayed automatically.

Call show when running a script or when the environment does not display figures automatically.
