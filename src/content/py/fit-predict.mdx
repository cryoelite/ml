This interface is the reason scikit-learn won. Every model — a linear
regression, a random forest, a gradient-boosted ensemble, a clustering
algorithm — exposes the same two methods, so swapping one for another is a
one-line change and comparing five of them is a for-loop.

The convention: `X` is a 2-D array of shape `(n_samples, n_features)`, capital
because it is a matrix; `y` is a 1-D array of length `n_samples`, lowercase
because it is a vector. Nearly every shape error you hit early on is `X`
having the wrong rank.
